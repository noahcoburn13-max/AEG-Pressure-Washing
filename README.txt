- Click-to-call and click-to-email

- No invented customer reviews, ratings, years, or job counts

To publish for free:
1. Keep index.html, styles.css, script.js, and the assets folder together.
2. Upload them to a free static hosting provider such as GitHub Pages.
3. Later replace the gallery placeholders with real project photos.
4. Add verified reviews and your actual service area when ready.
